# Project Technology Trends

Final Capstone for IBM Data Analyst
Professional Certificate on Coursera.

This project analyzes Stack Overflow
Developer Survey to decide what language
to teach and to whom.

### Business Problem

An IT training company wants to expand.
We need to predict which languages will
be in demand and who to teach them to.

### Where to Bring Data From?
### What Kind of Data is Required?

For this capstone, data comes from:

- Stack Overflow Annual Developer Survey
  (m5_survey_data_technologies_normalised.csv
  and demographics files)

Required data is:
- Languages Worked With (current year)
- Languages Want To Work With (next year)
- Databases Worked With / Want To Work With
- Number of respondents in each country
- Age, education, employment demographics

This is the data used to build the
dashboards and final recommendation.

Note: API collection and Web Scraping were
also completed as part of the certificate
to learn additional skills. They are not
part of this capstone pipeline.

### Objectives

- Clean and wrangle survey data with Pandas
- Explore data with EDA
- Find Top 10 languages current vs next year
- Visualize trends with Matplotlib
- Build 3 dashboards in IBM Cognos Analytics
- Recommend what to teach

### Analysis Done

- Current Year: Top 10 LanguageWorkedWith
- Next Year: Top 10 LanguageDesireNextYear
- Top databases and platforms
- Respondents by country
- Developer demographics dashboard

### Final Outcome

Outcome: Give data-driven advice on what
programming language to teach next.

Audience: Aspiring developers, recent
graduates, and professionals who want to
upskill in web dev and data science.

Prediction: Python, JavaScript, and SQL
show the strongest current use and future
desire. Best choice to teach this audience
for jobs and future growth.
